# Open questions

- **Reward page.** The idea: it appears only when (1) the person has built
  the special pattern of parts and (2) they have watched the marbles run
  correctly. Which puzzle(s) it's attached to, what the pattern is, and when
  exactly it appears are all undecided.
- **Adapt ttsim or write something new?** Settled: run ttsim itself, unchanged (docs/reuse-from-ttsim.md).
- **Tell fixed parts from the player's parts?** ttsim draws them the same. Undecided whether to mark them.
- **How many puzzles?** Eleven, in six stages; may change.
- **Sharing.** Settled: UpperStory's guide is free for non-commercial use
  with credit. Give credit to UpperStory and ttsim in the game and README.
